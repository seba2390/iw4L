# Black Ops 2 — fidelity ledger

Rule: Black Ops 2 matches run on Black Ops 2's own rules and data; no other
game's behaviour stands in. A rule that is not recovered is an `unknown!` in
`game_t6`, listed here with its id; `cargo xtask boundary` refuses an id that
is missing here.

Black Ops 2 ships its scripts as compiled bytecode, which IW4L does not execute.
Its matches run rules IW4L wrote for Black Ops 2 (Free for All, Team Deathmatch,
Classic zombies) on Black Ops 2's data; each such rule is listed below until it
is read from the game itself.

Severity: **V** visible, **A** audible, **G** gameplay, **I** invisible.

## Open

- [ ] **G** `t6.scripts.gametypes` (`GameScripts::program`): Black Ops 2
      multiplayer modes other than Free for All (`dm`) and Team Deathmatch
      (`war`) have no rules, so those matches are refused at load.
      *Needs:* Black Ops 2's rules for each mode.
- [ ] **G** `t6.scripts.zm_gametypes` (`GameScripts::program`): zombies maps
      run only Classic (`zclassic`); Grief, Turned and the TranZit locations
      are refused. *Needs:* Black Ops 2's zombies submode and location rules.
- [ ] **G** `t6.scripts.zclassic_on_mp` (`GameScripts::program`): Classic
      zombies on a multiplayer map is refused. *Needs:* a zombies map.
- [ ] **G** The Black Ops 2 program is compiled against Modern Warfare 2's
      builtin list (`session/src/games.rs`, `T6OnIw4Builtins`). *Needs:* Black
      Ops 2's builtin list.
