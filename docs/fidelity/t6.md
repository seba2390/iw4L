# Black Ops 2 — fidelity ledger

Rule: Black Ops 2 matches run on Black Ops 2's own rules and data; no other
game's behaviour stands in. A rule that is not recovered is an `unknown!` in
`game_t6`, listed here with its id; `cargo xtask boundary` refuses an id that
is missing here.

Black Ops 2 ships its scripts as compiled bytecode, which IW4L does not execute.
Its matches run rules IW4L wrote for Black Ops 2 (Free for All, Team Deathmatch,
Classic zombies) on Black Ops 2's data; each such rule is listed below until it
is read from the game itself.

The compiled modules themselves are read: `fastfile_t6::scripts` takes them
out of a zone and `gsc_t6::Module` parses each one's header and tables
(includes, animation trees, code, strings, exports, imports). All 612 modules
in the eleven zombies zones of the Steam install (543 distinct names) parse,
each table ending where the next begins: 9 044 exported functions, 1.9 MB of
code (`maps/mp/zombies/_zm.gsc`: 168 functions; `_zm_perks.gsc`: 95;
`_zm_powerups.gsc`: 102).

Severity: **V** visible, **A** audible, **G** gameplay, **I** invisible.

## Open

- [ ] **G** Black Ops 2's script bytecode is not executed, so its own zombies
      rules (`maps/mp/zombies/_zm*.gsc`, the map's `zm_<map>*.gsc`) do not
      run; the rules below stand where they would. Known so far (`gsc_t6`,
      checked on every module): opcodes are one byte and the interpreter
      dispatches 124 values (`OPCODE_LIMIT`); a function starts with one of
      two entry opcodes; each import's call sites hold its kind's opcode
      (reference, call, thread call, method call, method thread call) and a
      zero byte; bit 0x10 of an import's flags marks developer-only calls.
      Every opcode's operand layout and name is known (`gsc_t6::operand`,
      `gsc_t6::Opcode`, read from each handler: how it moves the instruction
      pointer, what it pushes, the error text it raises) and every function of
      the zombies zones decodes: 748 097 instructions, each call site an
      instruction start, each string and animation reference inside an
      operand, each jump (signed 16-bit offset) landing on an instruction of
      its function, each switch on its case table and each case on an
      instruction. A function ends at its last End or Return, alignment to 4
      and four bytes; what follows is padding. WaitTillMatch's byte (the
      match count) is read by notify when the waiter wakes, not by its handler.
      `gsc_t6::Translator` puts all 9 044 functions onto the GSC IR (SafeDecTop
      drops a waittill output the script leaves unnamed, unless the frame
      marker is on top);
      dvar names given by hash (`dvar_hash`, djb2 of the lowercased name,
      matched on 103 names the scripts also spell out) stay hashes: the
      engine finds a dvar by hash and takes an integer as one.
      `gsc_t6::build` links modules by the loader's rules: a call or
      reference without a namespace names the builtin of that name first
      (threads never do), then a function of its module, then of each module
      it includes, in order (private functions only from their own module);
      a call may pass no more parameters than the function declares; too many
      for a builtin is reported and linked, too few or an unknown name refuses
      the scripts. Checked against the modules the running game linked:
      every builtin call site and 9 514 of 9 515 script call sites agree (the
      other links a duplicate the game kept from the map's patch zone).
      With `IW4L_T6_OWN_SCRIPTS` set (while they are brought up), a zombies
      match runs them in place of the rules below: modules, configs and tables
      from `common_zm`, `patch_zm`, `so_zclassic_<map>`, the map and
      `<map>_patch` in that order, then the captured downloaded patch
      (`t6.scripts.ffotd`); started as the engine starts a level (the map's
      `gamemode_callback_setup`, the gametype's `main`, the map's `main`, then
      `codecallback_startgametype` and `codecallback_finalizeinitialization`),
      on the map's default gametype, start location and gametype group from
      `zm/gametypestable.csv` (`t6.scripts.zm_start`). The scripts the engine
      loads itself (`codescripts/delete`, `codescripts/struct`, `_medals`,
      `_rank`, `_persistence`, `_spawning`, `maps/mp/zombies/_zm`) are loaded
      with them. Builtins are
      `sim::script::host::natives::t6`, each read from its handler; the rest
      fail as not implemented. The gametype's own zone is taken as
      `so_zclassic_<map>` whatever the gametype.
      *Needs:* the builtins.

### Rules IW4L wrote for Black Ops 2 (not read from the game)

- [ ] **G** Free for All / Team Deathmatch match flow is IW4L's
      (`sim/src/script/host/t6_gametype.rs`): warmup ends at once, 2 s respawn
      delay, score/time-limit end, restart 100 ticks after the end, Use skips
      the killcam, team balance and friendly-fire block. Score-limit fallbacks
      30 (`dm`) / 75 (`war`) when `scr_<gametype>_scorelimit` is absent
      (`game_t6`, `ModeRules::default_score_limit`).
- [ ] **G** Classic zombies is IW4L's (`sim/src/script/host/t6_zombies*.rs`):
      round health, population and spawn-delay formulas (`rounds.rs`), 24 alive
      at most, actor hull 14×64, actor speed 35 + 7·round up to 170, melee
      damage 50, start points 500, prices by weapon/perk name (wall guns
      500/1000/1200, door 750, box 950, Pack-a-Punch 5000, perks
      1500–4000), Jugger-Nog 250 health, revive 7 s, bleed-out 45 s, 10 s
      between rounds, board repair points.
- [ ] **G** Power-ups (`t6_zombies/powerups.rs`): drop threshold 2000 points,
      30 s durations, the drop bag.
- [ ] **G** Origins (`t6_zombies/origins*.rs`): generator price 200 per
      player, dig odds and rewards, **staff parts from digging (15 % after
      round 5) — not how Origins awards staff parts**, staff abilities,
      weather cadence (rain `350/level`, snow `500/level`).
- [ ] **G** Origins staff upgrades and quest (`t6_zombies/origins_staff.rs`,
      `origins_dig.rs`) — upgrades and staff-part collection are still IW4L
      rules, not recovered gameplay. The first quest transition records a
      complete upgraded-staff set, presents the four map-authored elemental
      holders, and returns the staffs after all four placements. The
      standalone runtime returns each staff to its placing player rather than
      restoring map pickup props. The puzzle-room portal, 100-soul defence,
      drone flight, and final portal stages remain unimplemented.
- [ ] **G** Zombie AI (`t6_zombies.rs`): A* over collision-tested path nodes,
      crowd separation, repath timing, window tear/entry timings.
- [ ] **V** `t6.hud.code_hud` (`HudRules::code_hud`): Black Ops 2's own HUD is
      not known; Modern Warfare 2's code-drawn HUD is off for it. The HUD
      (`ui/src/t6_hud.rs`) is drawn by IW4L with English text
      ("ROUND", "HEALTH", VICTORY/DEFEAT/DRAW, "GAME OVER", "DOWNED - waiting
      for revive", "KILLCAM"); zombie prompts are script hud elems with English
      text and prices (`t6_zombies.rs` `make_hud`). Black Ops 2's own HUD is not
      used.
- [ ] **V** Pause and create-a-class menus are IW4L's layout over Black Ops 2
      art (`ui/src/t6_menu.rs`).
- [ ] **V** Player body animation: a hand-picked table of 20 Black Ops 2 clips
      on IW4L's player-animation slots (`asset_anim/src/t6_player.rs`).

## Closed

- [x] **V/G** Zombies maps never loaded their own patch zone: it was looked
      for as `patch_<map>`; the engine loads `<map>_patch` after the map.

- [x] **G** Black Ops 2's program compiled against an empty builtin list. It
      now compiles against Black Ops 2's own (`game_t6/src/builtins.rs`: 547
      functions, 935 methods, each with the parameters a call may pass and
      whether only developer blocks may call it), read from the executable's
      tables in the order its loader searches them.

- [x] **G/A** Name lookups fell back to another game's asset of the same name
      when Black Ops 2's had none: actor animation-tree leaves and script animation
      clips (any game's clip), a map's createfx rawfiles and FX sounds (an
      alias unique across games). Each now looks only in its own game.

- [x] **V/A** Black Ops 2 matches played Modern Warfare 2's effects where IW4L's
      code names one (knife flesh hit `impacts/flesh_hit_knife`, glass shatter,
      motion-tracker light) and an effect's sound resolved Modern Warfare 2's
      alias first. Both now resolve in the Black Ops 2 data: the code's effect name
      in the match's game, an effect's sound in that effect's game. Where
      Black Ops 2 has no effect of that name nothing plays (which effect Black Ops 2
      uses there is not known).

- [x] **A** Black Ops 2 maps loaded Modern Warfare 2's and Black Ops' sound
      banks (`common_mp`) under their own; now only Black Ops 2's.

- [x] **G** Black Ops 2 matches read Modern Warfare 2's `default_xboxlive.cfg`
      (its `scr_dm_scorelimit` 1500 was Black Ops 2's Free for All limit) and
      got Modern Warfare 2's `onlinegame 1` and `sv_maxclients 18`. Gone.

- [x] **G** The Black Ops 2 program was compiled against Modern Warfare 2's
      builtin list (`Catalog::t6()`, then `T6OnIw4Builtins` in `games.rs`), and
      its generated map main carried Modern Warfare 2's animated-model table.
      Both gone: empty Black Ops 2 list, no table.
