# Black Ops 2 — fidelity ledger

Rule: Black Ops 2 matches run on Black Ops 2's own rules and data; no other
game's behaviour stands in. A rule that is not recovered is an `unknown!` in
`game_t6`, listed here with its id; `cargo xtask boundary` refuses an id that
is missing here.

Black Ops 2 ships its scripts as compiled bytecode. IW4L translates the compiled
modules (`gsc_t6`) and runs them for Classic zombies on every map but Origins.
Free for All, Team Deathmatch and Origins' Classic still run rules IW4L wrote for
Black Ops 2 on its data; each such rule is listed below until it is read from
the game itself. Some ids name a described deviation rather than an `unknown!`
in the code.

The compiled modules themselves are read: `fastfile_t6::scripts` takes them
out of a zone and `gsc_t6::Module` parses each one's header and tables
(includes, animation trees, code, strings, exports, imports). All 612 modules
in the eleven zombies zones of the Steam install (543 distinct names) parse,
each table ending where the next begins: 9 044 exported functions, 1.9 MB of
code (`maps/mp/zombies/_zm.gsc`: 168 functions; `_zm_perks.gsc`: 95;
`_zm_powerups.gsc`: 102).

Severity: **V** visible, **A** audible, **G** gameplay, **I** invisible.

## Open

### Zombies scripts and engine

- [ ] **G** Where Black Ops 2's own scripts (*Closed*: the bytecode, switch
      selector range `−0x7E8000..=0x7FFFFF`, and djb2 dvar hash resolution over
      all 3 004 registered dvars) still differ from the engine: the gametype's
      own zone is taken as `so_zclassic_<map>` whatever the gametype. A builtin
      not implemented fails as such (none on Nuketown, TranZit and Buried; Die
      Rise and Mob of the Dead are not measured).
- [ ] **G** Path nodes are read from the game world as the zone has them; the
      engine drops each to the floor at load (a −15,−15,0 to 15,15,30 sweep

      check; a node that fails becomes a bad node). *Needs:* that trace.
